# おもいでリマスター Webサイト

動画高解像化サービス「おもいでリマスター」のサイト。運営元は屋号「Corota AI Lab.」(既存のデータサイエンス/AI導入支援スタジオ、corota-ai-lab.com で別事業を運営中)。事業内容の検討経緯は [../Business/PLAN.md](../Business/PLAN.md) を参照。

**ホスティング**: 既存の corota-ai-lab.com とは別サービス・別ターゲット(BtoB地域データサイエンス vs BtoC全国向け動画復元)のため、サブドメイン(例: omoide-remaster.corota-ai-lab.com)で公開予定。

## サイトに載せる予定の内容(PLAN.mdより)

- サービス概要・ビフォーアフター実例(フリー素材/自作の劣化サンプルを使用)
- 料金プラン(標準/ハイスピード/高品質、都度見積もり)
- 問い合わせ窓口(専用のGmailアドレスを別途用意予定)
- 特定商取引法に基づく表記
- プライバシーポリシー
- 利用規約
